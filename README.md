# Archaea_LTT
Analysis pipeline for all the 16S V4 sequencing runs of the BATS/BIOS-SCOPE time series data. Including: DADA2 pipeline, feature table and metadata concatenation etc. 

## BATS/BIOS-SCOPE 16SV4 RUNS - 1991 to 2024 
473, 751, 755, 891, 985, 991, 993, 997, 1001, 1008, 1016, 1024, 1031, LTT_J24_L1 to L7.
